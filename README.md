# SWYNEX Data Analyst Internship – Task 1
## Data Cleaning and Preparation

### 📌 Project Overview
This project is part of **Task 1** of my Data Analyst Internship at **SWYNEX**.

The objective is to explore a retail dataset, identify data quality issues, and practice data cleaning and preparation using MySQL.

### 🛠️ Tools & Technologies
- MySQL
- MySQL Workbench
- SQL

### 📊 Tasks Performed
1. Explored the dataset and checked its structure.
2. Displayed the first 10 records.
3. Identified and counted missing values.
4. Checked invalid values in Quantity and UnitPrice.
5. Identified extra spaces in Description and Country.
6. Checked invalid dates in InvoiceDate.
7. Practiced SQL data-cleaning operations.

### 🔍 SQL Concepts Used
- `SELECT`
- `WHERE`
- `COUNT()`
- `IS NULL`
- `TRIM()`
- `REGEXP`
- `STR_TO_DATE()`
